# SpendWise – Interactive Personal Budget Tracker

## Project Description

SpendWise is a personal budget tracker built with HTML, CSS, and JavaScript. It helps users view a monthly budget, track expenses, organize spending by category, and monitor their remaining balance.

This project was developed as part of the Power Learn Project (PLP) Software Engineering Training.

## Features

- Dashboard showing monthly budget, total spent, and remaining balance.
- Expense categories such as Food, Transport, Rent, Entertainment, Savings, and Utilities.
- Add new expenses using an interactive form.
- Display recent transactions.
- Update category totals when a new expense is added.
- Simple and user-friendly dashboard design.

## Technologies Used

- HTML5 – page structure.
- CSS3 – styling and layout.
- JavaScript – interactive features and expense calculations.

## Project Files

- `index.html` – dashboard structure.
- `style.css` – page styling.
- `script.js` – interactive features and calculations.
- `README.md` – project documentation.

## Deployment Summary

SpendWise was deployed using Netlify and connected to the GitHub repository.

Deployment details:

- Hosting platform: Netlify.
- Source code: GitHub.
- Production branch: `main`.
- Build command: Not required because this is a static HTML, CSS, and JavaScript project.
- Custom Netlify subdomain: `spendwise-peter.netlify.app`.
- Automatic deployment: Enabled.

A change committed to the GitHub `main` branch triggered a new Netlify production deployment. The updated footer was then confirmed on the live website.

## Challenges Faced

Connecting GitHub to Netlify required an additional authorization step. This was resolved by restarting the connection process and granting Netlify access to the project repository.
