\# My Budget Tracker



\## Project Description



My Budget Tracker is a simple web page designed to help users record and review their daily expenses. This project was developed using HTML and CSS as part of the PLP Software Engineering Training Week 2 assignment.



\## Files in This Project



\- \*\*index.html\*\* — Contains the structure of the webpage, expense form, category dropdown, expense table, help section, logo, and embedded budgeting video.

\- \*\*Style.css\*\* — Controls the appearance of the webpage, including colors, fonts, form fields, table borders, alternating row colors, hover effects, and responsive styling.

\- \*\*README.md\*\* — Explains the purpose and features of the project.



\## Features



1\. An expense form with fields for expense name, amount, category, and date.

2\. A category dropdown with Food, Transport, Rent, Entertainment, and Other.

3\. An expense table containing five sample expenses.

4\. A logo image near the main heading.

5\. An embedded YouTube budgeting tips video.

6\. A collapsible "How to use this tracker" section.

7\. CSS styling with advanced selectors, including `:focus`, `:not()`, `:nth-child(even)`, and `:hover`.

8\. Responsive styling for smaller screens.



\## Technologies Used



\- HTML5

\- CSS3



\## How to Run



1\. Download or clone this project repository.

2\. Open `index.html` in a web browser.

3\. View the expense form, sample expense table, help section, and budgeting video.



\## Note



The Add Expense button is a placeholder for future JavaScript functionality. The table currently contains sample data and does not automatically add new expenses.
